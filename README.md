# Инвестиционный портфель

**Версия 1.0** | _Web - приложение_ | **Web, Django**

Веб‑приложение для управления инвестиционным портфелем с отслеживанием курсов валют и расчётом прибыли.

---

## Возможности

- Приложение позволяет пользователям:
  - _управлять инвестиционным портфелем_
  - _покупать и продавать **валюту**, **акции** или **фьючерсы**_
  - _отслеживать актуальную стоимость активов_
  - _анализировать прибыль и получать уведомления о выгодных сделках_

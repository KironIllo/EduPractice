[*] --> Инициализирован : создан объект\n(параметры SMTP)

Инициализирован --> Генерация_кода : Отправка кода()
Генерация_кода --> Формирование_письма
Формирование_письма --> Подключение_к_SMTP

Подключение_к_SMTP --> Аутентификация : соединение установлено
Подключение_к_SMTP --> Ошибка_подключения : таймаут/отказ

Аутентификация --> Отправка : логин успешен
Аутентификация --> Ошибка_аутентификации : неверные учётные данные

Отправка --> Закрытие_соединения
Закрытие_соединения --> [*] : возврат success

Ошибка_подключения --> [*] : возврат ошибки
Ошибка_аутентификации --> [*] : возврат ошибки
Отправка --> Ошибка_SMTP : исключение при sendmail
Ошибка_SMTP --> [*] : возврат ошибки
@enduml
